# 单线通信地址绑定协议说明

## 1. 协议背景与目的

本协议用于 **遥控器、充电板、按摩板** 三者之间的 **地址绑定与校验通信**。

### 设计目标

- 在 **遥控器充电** 时，自动完成无线地址绑定
- 通信引脚 **仅 1 根信号线**
- **无应答机制**，通过多次发送保证可靠性
- 后续无线数据通过地址码校验，防止误触发

------

## 2. 系统角色说明

| 设备   | 作用                           |
| ------ | ------------------------------ |
| 遥控器 | 发送自身无线地址               |
| 充电板 | 中继地址数据，并负责充电控制   |
| 按摩板 | 保存地址，用于后续无线数据校验 |

------

## 3. 通信总体流程

```text
遥控器
   │（充电时发送地址，3 次）
   ▼
充电板
   │（转发地址，3 次）
   ▼
按摩板
   │
   ├─ 保存地址
   └─ 后续无线数据 → 地址校验 → 是否处理
```

------

## 4. 地址数据定义

- **地址长度**：2 字节（16 bit）
- **发送次数**：3 次
- **应答机制**：无应答
- **比特顺序**：高位在前（MSB First，推荐）

------

## 5. 单线通信物理协议

### 5.1 电平约定

| 状态   | 含义          |
| ------ | ------------- |
| 高电平 | 主动发送      |
| 低电平 | 空闲 / 位间隔 |

------

## 6. 同步码（Sync）

### 6.1 作用

用于告诉接收端：

> **一帧新的地址数据即将开始**

### 6.2 时序定义

```text
     ┌───────────┐
     │   HIGH    │
─────┘           └────────────────────
        400us             9ms
```

| 电平   | 时间   |
| ------ | ------ |
| 高电平 | 400 μs |
| 低电平 | 9 ms   |

------

## 7. 数据位编码规则

### 7.1 Bit 定义

| Bit 值 | 高电平 | 低电平 |
| ------ | ------ | ------ |
| bit0   | 400 μs | 800 μs |
| bit1   | 1 ms   | 200 μs |

------

### 7.2 Bit0 时序示意

```text
     ┌───────────┐
     │   HIGH    │
─────┘           └────────────────────
        400us             800us
```

------

### 7.3 Bit1 时序示意

```text
     ┌──────────────────────┐
     │         HIGH         │
─────┘                      └────────
            1ms                 200us
```

------

## 8. 地址帧结构

```text
┌──── Sync ────┐ ┌────── Address (16 bit) ──────┐
│ 400usH+9msL  │ │      b15 b14 ... b1 b0       │
└──────────────┘ └──────────────────────────────┘
```

### 发送规则

- 每一帧 = 同步码 + 16 个数据位
- 每个地址帧 **完整发送 3 次**
- 帧与帧之间允许空闲低电平

------

## 9. 遥控器 → 充电板通信

### 触发条件

- 遥控器插入充电
- 进入充电状态后立即发送地址

### 行为说明

1. 发送同步码
2. 发送 16bit 地址
3. 重复上述流程 **3 次**
4. 不等待应答

------

## 10. 充电板 → 按摩板通信

### 发送方式

- 使用 **充电引脚** 进行单线通信
- 协议格式 **与遥控器完全一致**

### 行为流程

1. 接收遥控器地址（至少一次有效）
2. 将地址按协议转发给按摩板
3. 重复发送 **3 次**
4. 发送完成后，拉高充电引脚

------

## 11. 充电与通信复用设计

### 11.1 按摩板充电判定规则

| 条件                    | 说明           |
| ----------------------- | -------------- |
| 充电引脚持续高电平 ≥ 1s | 判定为真正充电 |
| 高电平 < 1s             | 仅认为是通信   |

------

### 11.2 充电 LED 处理策略

为避免用户误以为“未充电”：

- **一旦接收到合法地址数据**
  - 充电 LED 可立即点亮
- **实际充电逻辑**
  - 仍以充电引脚 ≥ 1s 高电平为准

------

## 12. 按摩板地址存储与校验逻辑

### 12.1 地址保存

- 接收到完整有效地址后
- 保存到非易失存储（如 Flash / EEPROM）

------

### 12.2 无线数据处理流程

```text
接收到无线数据
	│
	▼
解析地址码
    │
    ├─ 地址一致 → 处理数据
    │
    └─ 地址不一致 → 丢弃数据
```

------

## 13. 协议可靠性设计说明

| 设计点             | 说明           |
| ------------------ | -------------- |
| 多次发送           | 弥补无应答缺陷 |
| 长同步码           | 防止误触发     |
| 高低电平时间差异大 | 提高抗干扰能力 |
| 地址校验           | 防止串扰或误控 |

------

## 14. 注意事项

- 定时精度建议 ≤ ±10%
- 建议使用 **定时器捕获** 或 **输入中断+计数**
- 接收端需具备：
  - 同步码检测
  - 位宽判定
  - 超时复位机制
